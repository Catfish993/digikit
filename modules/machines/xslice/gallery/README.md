# XSLICE

An extra machine in the SRC machine list: a clone of MANUAL SLICE with its own name (XSlice) and a SRC page that
shows a third knob, the CFADE row that MANUAL SLICE leaves unused. It plays like MANUAL SLICE.

Projects saved with an XSLICE track keep the machine when loaded on the same patched firmware. On stock firmware the
track loads as SAMPLE; saving there removes the machine.

Needs Digitakt II OS 1.17 (1.16 untested). Not for Digitone II.
