# Acid

A TB-303-style bass for the Digitakt II, as two machines: **Acid Saw** and **Acid Square**. One oscillator runs through a squelchy
resonant four-pole lowpass with its own decaying envelope; trigs at velocity 112 and above are accented (shorter, wider filter sweep and
more level), as on a 303. The track's FLTR, AMP and FX pages still run after it, so the overdrive and the stock filter stack on top.

| knob | range |
|---|---|
| **CUT** | base cutoff, 40 Hz .. 5.1 kHz |
| **RES** | resonance, up to the edge of self-oscillation |
| **ENV** | how far the filter envelope opens the cutoff, 0 .. 5 octaves |
| **DEC** | filter envelope time, 0.15 .. 2.4 s (accented trigs use 0.2 s) |

Program a line with short AMP decays, put accents on the trigs you want to bite, and ride CUT and RES (both lock per step).
