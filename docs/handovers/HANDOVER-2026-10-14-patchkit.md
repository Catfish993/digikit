## State

- **patchkit** (`native/patchkit`, Rust; CLI and `patchkit.wasm` give byte-identical output) is a generic patcher:
  `.syx` codec with aPLib packing, HMAC and checksums; port lockfiles (`devices/ports/*.toml`, generated by
  `mise run port:resolve` from anchor rules; addresses and SHA-256 only); linker for `.dko.json` objects; primitives
  P1-P6 (sections copied from the user's image, registries and entries, expressions, typed writes, ColdFire and
  SHARC hooks, device filters); conflicts, claims, canonical order, patch record, `plan.json`, `explain`, `verify`.
  Safety rules: sections 2, 4 and 8 never change; container at most 0x300000 bytes; boot-ROM rules on section 7.
- **Frameworks are modules**: `core/expansion` (ColdFire loader into 1.33 MiB DT2 / 24.8 MiB DN2 of free DDR),
  `core/machines`, `core/params`, `core/dsp-voice` (DT2 and DN2 assembly side by side).
- **Content modules**: `digikit/master-gain`, `digikit/master-drive`, `test/xslice`, `digikit/pluck` (Karplus-Strong, DT2
  and DN2, own parameters; DN2 own pages), plus test modules.
- **Machine type numbers are permanent**: `modules/core/machines/types.toml` (DT2 7..23, DN2 5..23); unselected numbers
  are gap rows; `mise run patch:new -- machines/X --machine` allocates the next number. The CLI adds `requires`.
- **Firmware**: DT2 1.16/1.17, DN2 1.11/1.12 supported (only MAIN OS and META differ between those pairs).
- **Emulator**: runs the real bootstrap (recovery proven: [FUNC] at power-on, [TRIG 4], MIDI DIN); coupled cold boot
  of a patched MAIN with DSP audio; ColdFire code runs from RAM; health events (`fault`, `halt`, `stall`, `underrun`);
  conditional Type 7a fixed (cores regenerated); SHARC code watch on exact spans (patched PLUCK 42 -> 4.5 DSP s per
  audio s).
- **Dev loop and tests**: `mise run patch`, `patch:new`, `patch:build`, `patch:explain`, `inject`, `patch:dev`,
  `patch:test` (smoke matrix, 15 cells, about 5 min with `--jobs 4`), `patch:proofs` (quick tier of ten proof tools,
  387 s); `tools/pk_break.py` broken images that the quick tier must fail.
- **Web**: `/patch` gallery (patch in the browser, boot, download; the firmware never leaves the browser).
- **Docs**: `docs/MODULE-AUTHORING.md` (short path), `docs/PATCHING.md`, `modules/README.md`, skills
  `digikit-module` and `firmware-query`.

## Rules learned this milestone (also in AGENTS.md)

- Agents never wait with `tail -f`; poll with a bound. Stop only processes you started; never pkill emulators.
- Lane agents iterate and finish on the quick tier; integration = verify + smoke matrix; full proofs only before a
  merge to `main`. Do not re-run old full proofs to re-measure a recorded baseline.
- Hardware stays untouched until everything works in the emulator (Em's decision).
